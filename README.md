### Project: Network Traffic Analysis & Threat Investigation Using Wireshark
### 🌐 1. Network Traffic Analysis & Threat Investigation
**Tool:** Wireshark | **Environment:** Windows | **Category:** Network Security & Threat Analysis

Performed PCAP analysis to investigate network activity associated with a Windows system, identify suspicious communications, examine network protocols, and investigate potential exposure of authentication credentials.

**Investigation Activities:**
- Analysed the Protocol Hierarchy to identify protocols present in the packet capture and establish an initial understanding of network activity.
- Investigated attacker and destination IP addresses and identified associated domain names using DNS records and application-layer information, including HTTP Host headers.
- Examined UDP traffic to identify source and destination ports and determine the protocols and services involved.
- Investigated secure communication protocols and identified the ports associated with relevant services.
- Followed TCP streams to reconstruct conversations and examine requests, responses, and application-layer activity.
- Examined captured traffic for potential exposure of usernames, passwords, and authentication information.
- Used Wireshark display filters to isolate relevant packets and investigate specific network fields.

**Technical Skills Demonstrated:**
- PCAP analysis and network traffic inspection
- DNS investigation and domain identification
- UDP/TCP protocol analysis
- Port and service identification
- Network stream reconstruction
- Authentication traffic analysis
- Protocol identification and validation
**Tools & Technologies**:
Wireshark, PCAP, DNS, UDP, TCP/IP, HTTP, TLS, Network Protocol Analysis.
